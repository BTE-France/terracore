The Geo module lives in the `net.buildtheearth.terracore.geo` package. It brings:
- support for geographic projections (i.e. mapping points from a globe onto a flat Cartesian plane and vice versa),
  in the `projection` subpackage;
- quality of life classes to help present geographic data in human friendly ways, like `CardinalDirection` and `CoordinateParseUtils`;
- data structures for efficient spatial computations:
  - bounding volume hierarchy structures (BVH) in the `bvh` subpackage;
  - an interval tree structure in the `interval` subpackage;
- various geo maths in the `GeoMaths` class.

The Minecraft module lives in the `net.buildtheearth.terracore.minecraft` and implements object-oriented abstractions over Minecraft concepts.

It has implementations for:
- *Identifiers* (a.k.a. *Resource locations*, e.g. `minecraft:stone`)
- *Blocks states* (a block identifier like `minecraft:oak_log` and the properties that definite it when placed in the work, like `facing=north`)
- *Biomes*
- *BlockPos* (Cartesian coordinates of a block in a Minecraft world)
- *ChunkPos* (Cartesian coordinates of a chunk in a Minecraft world)
